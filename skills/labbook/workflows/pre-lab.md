# Pre-Lab

Goal: maximize information gained during scarce physical robot access.

For each planned test record:
- question/hypothesis;
- why physical hardware is required;
- exact code/config candidate;
- observable success/failure criteria;
- evidence/instrumentation required;
- expected safety constraints;
- fallback or isolation test.

Prioritize tests by information value, dependency order, and physical necessity.

Prepare a **minimum useful experiment** so the session still produces knowledge if the main objective fails.

Before lab time, verify logging/video/telemetry, dependencies, configuration, rollback path, and known-safe baseline where applicable. Flag unreviewed high-risk control changes.

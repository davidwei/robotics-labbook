# Post-Lab

This is the primary deep-review phase.

Produce a review package containing:

## 1. Timeline
Reconstruct runs, observations, agent sessions, and material changes in chronological order.

## 2. Change audit
Explain material code/config changes. Mark each as tested/untested and reviewed/unreviewed. Highlight control/safety-sensitive changes.

## 3. Run comparison
Compare relevant runs against code/config/evidence. Identify correlations without claiming causality unless the experiment supports it.

## 4. Interpretation
Separate:
- direct observations;
- hypotheses/candidate explanations;
- proposed findings;
- contradictions/missing evidence;
- conclusions supported strongly enough for human review.

## 5. Next tests
Design high-information experiments, especially tests that distinguish competing explanations and tests that can be completed in simulation before using the robot.

## 6. Human review
Do not silently promote consequential proposed findings to validated/reusable knowledge. Preserve corrections and superseded interpretations.

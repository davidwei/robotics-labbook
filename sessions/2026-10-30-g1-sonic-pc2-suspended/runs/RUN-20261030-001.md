# RUN-20261030-001 — feet-clear INIT and local O

SONIC revision `1fa5f7fa3966cbd4845c4e641d13c3f0cd5b0d9b` ran on PC2 with
keyboard input while G1-29 was fully suspended. PICO never started the policy.
The operator described the motion as smooth. The default-pose transition settled
in about three seconds without a sampled motor error. Because terminal output was returned after a 30-second poll, the
robot remained commanded at the default pose for roughly 26 additional seconds
before local `O` was sent.

`O` was accepted and SONIC exited normally. Independent capture saw command
publication stop, but did not see the documented damping frame or any resumed
stock LowCmd during the following 5.37 seconds. The unloaded joints then relaxed;
the largest measured post-stop change was 0.406 rad at the right elbow. This run
therefore demonstrates the INIT motion and process exit under these conditions.
A delayed three-second check captured live LowState and torso IMU but zero
LowCmd, confirming the prior stock stream had not resumed by 01:53:31. Damping
and stock-controller handover are not validated. Further motion testing should
not proceed without a fresh, separately authorized setup. The operator recognized
the result as the previously observed development-mode behavior: SONIC does not
restore the original mode when it exits. This is accepted as a gantry-only
operating limitation. Untethered testing remains blocked.

See `RUN-20261030-001.yaml` for configuration, measured values, coverage and
evidence limitations.
